Institutional Data Extraction & Automation Toolkit
Business Context
This repository highlights the core ETL (Extract, Transform, Load) and automation logic developed during my Data Engineering internship at Bank Al-Maghrib (Central Bank of Morocco). The primary objective of this project was to modernize the Department of Statistics and Data Management by replacing manual data-entry bottlenecks with an automated, high-precision data pipeline.
Key Features & Architecture
Intelligent PDF Parsing: Automated complex data extraction workflows from unstructured PDF documents using Python machine learning libraries.  
Algorithmic Data Cleansing: Implemented the Levenshtein distance algorithm to cross-reference and refine multi-source datasets containing over 3000 records.  
Automated Web Harvesting: Engineered efficient web scraping scripts to continuously monitor, harvest, and structure critical data from official web pages.  
OS-Level Integration: Leveraged the Windows API via Python to automate daily system-level tasks and schedule pipeline executions.  
Quantifiable Impact
95% Data Accuracy: Successfully resolved hundreds of duplicate entries and anomalies across institutional databases.  
100% Reduction in Bottlenecks: Fully eliminated routine manual data-entry tasks.  
Time Optimization: Significantly reduced overall manual processing time, allowing senior data engineers to focus on advanced analytics.  
Technical StackLanguage: Python
Concepts: Natural Language Processing (NLP), Web Scraping, String Metrics (Levenshtein), Process Automation, Windows API
Note: Due to strict confidentiality agreements with Bank Al-Maghrib, the code provided in this repository is a sanitized, generalized version of the original architecture. No sensitive institutional data is included.
